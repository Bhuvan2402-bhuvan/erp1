Slide 09 // Deep Dive 1

Anti-Proxy QR Attendance & Gamified Points

09 / 14
🛡️ Anti-Proxy TOTP QR Gate
• Time-sensitive TOTP QR generator on coordinator device.
• Prevents attendance fraud via screenshot sharing.
• Logs timestamped records with student ID, event ID, presence, and auditor signature.
🏆 Gamified Points & Tier Badges
• 🥉 Bronze Badge: 0 – 49 Points
• 🥈 Silver Badge: 50 – 149 Points
• 🥇 Gold Badge: 150 – 299 Points
• 💎 Platinum Badge: 300+ Points
🗣️
Speaker Notes: By dynamic TOTP generation, attendance cannot be faked via shared screenshots. Points directly drive achievement tier badges.

10 / 14

Speaker Notes: The financial ledger ensures zero financial ambiguity, while circular broadcasts guarantee instant notification delivery to all registered students.

Slide 13 // Security & Hardening

Security & Rate Limiting Framework

13 / 14
🛡️ IP Rate Limiting (lib/rate-limit.js)
Sliding-window IP rate limiting protects authentication endpoints against brute-force attacks.
📝 Zod Schema Validation (lib/validations.js)
Strict schema validation sanitizes all request payloads before hitting database handlers.
🔒 API Response Sanitizer
Global helper wrappers mask raw database tracebacks to prevent schema leakage.
🌐 Security Headers
Configured with X-Frame-Options: DENY, nosniff, and strict referrer policy.
🗣️
Speaker Notes: Security is integrated at all layers—from IP rate limiting to Zod payload validation and error sanitization.
